RePlate
Save a meal, share the feel.

## Problem Statement
Large amounts of safe, surplus food from restaurants, events, and other food-serving activities often go to waste because there is no simple system to coordinate its availability, pickup, and redistribution.

## Solution
RePlate is a web-based platform designed to connect surplus food sources with organizations that can help redistribute the food. It aims to make the rescue process more organized, time-sensitive, and traceable.

## Features
- Surplus food listing
- Real-time food rescue workflow
- Location-based matching
- Organization/NGO participation
- Verification and trust features
- Pickup and rescue tracking
- Impact tracking
- User-friendly interface

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Setup Instructions
1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Navigate through the prototype.

No backend or additional installation is required for the current prototype.
